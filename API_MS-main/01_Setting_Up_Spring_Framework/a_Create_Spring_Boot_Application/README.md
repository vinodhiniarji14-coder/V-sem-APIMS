# Experiment 1 — Setting up Spring Framework
## Sub-question (a): Create and run a Spring Boot application using Spring Initializr

### Aim
To create and run a Spring Boot application generated via Spring Initializr, exposing two simple GET endpoints.

### Requirements
- JDK 17+
- Apache Maven 3.9+
- Internet access only for the *first* `mvn` build (to download dependencies) — no internet required to run the app afterwards
- Spring Boot 3.3.4

### Project Structure
```
a_Create_Spring_Boot_Application/
├── pom.xml
├── src/main/java/com/example/demo/
│   ├── DemoApplication.java
│   └── HelloController.java
├── src/main/resources/application.properties
└── src/test/java/com/example/demo/DemoApplicationTests.java
```

### Dependencies Used
- `spring-boot-starter-web` — embedded Tomcat + Spring MVC for REST endpoints
- `spring-boot-starter-test` (test scope) — JUnit 5, Spring Test

### Explanation
`DemoApplication` is the `@SpringBootApplication` entry point that boots an embedded Tomcat server on port 8080. `HelloController` is a `@RestController` exposing `/` and `/hello`, both returning plain text.

### How to Run
```bash
mvn clean spring-boot:run
```
or build a jar and run it:
```bash
mvn clean package
java -jar target/exp01a-hello-world-0.0.1-SNAPSHOT.jar
```

### API Endpoints
| Method | URL | Response |
|---|---|---|
| GET | http://localhost:8080/ | `Welcome to Spring Boot Application` |
| GET | http://localhost:8080/hello | `Hello World from Spring Boot!` |

### curl Examples
```bash
curl http://localhost:8080/
curl http://localhost:8080/hello
```

### Expected Output
Browser/curl shows the exact strings above with HTTP 200 OK.

### Common Errors & Fixes
- **Port 8080 already in use** → add `server.port=8081` to `application.properties` or stop the conflicting process.
- **`mvn: command not found`** → install Maven or use the wrapper (`./mvnw`) if generated by Spring Initializr.
- **404 on `/`** → make sure no other `@RequestMapping("/")` conflicts exist; only `HelloController` should define it here.

### Verification Steps
1. Run `mvn clean test` — `contextLoads()` should pass, confirming the Spring context starts.
2. Start the app and hit both endpoints with curl/browser; confirm exact text and HTTP 200.
